The swatches below are the full design palette, handy when you design a page around FlatifyCSS. The framework itself uses four shades of each color, you can find them in the [palette variables](#palette-variables) table.

## Palette variables

Every color has four shades and each one is a CSS variable with this pattern: `--flatify__color-{name}-{shade}`, for example `--flatify__color-red-dark`. The state colors like `success` and `danger` are just aliases, so if you change the green color, success changes too.

## Base colors

Background and text colors are separate from the palette:

| CSS variable | Default | Used for |
| --- | --- | --- |
| `--flatify__bg-color` | <ColorIndicator inline color="#ffffff" title="#ffffff" /> | Page background |
| `--flatify__bg-color-dark` | <ColorIndicator inline color="#f1f4f7" title="#f1f4f7" /> | Default background of buttons, alerts, menus and form elements |
| `--flatify__bg-color-darker` | <ColorIndicator inline color="#ced9e3" title="#ced9e3" /> | Default border color of most components |
| `--flatify__bg-color-darkest` | <ColorIndicator inline color="#809cb6" title="#809cb6" /> | The darkest gray, free for your own designs |
| `--flatify__txt-color` | <ColorIndicator inline color="#2e4051" title="#2e4051" /> | Text |
| `--flatify__txt-color-light` | <ColorIndicator inline color="#77838e" title="#77838e" /> | Muted text |
| `--flatify__txt-color-dark` | <ColorIndicator inline color="#1e2a35" title="#1e2a35" /> | Darker text, like highlighted text |
| `--flatify__txt-color-inverted` | <ColorIndicator inline color="#ffffff" title="#ffffff" /> | Text on colored backgrounds, like badges |

## Changing colors

If you build FlatifyCSS with Sass, change the color variables in `_config.scss` (like `$BLUE` or `$ACCENT_COLOR`) and the light and dark shades are generated for you. With the compiled CSS, override the CSS variables instead:

```css title="style.css"
:root {
  --flatify__color-accent-primary: #8e44ad;
  --flatify__color-accent-light: #c39bd3;
  --flatify__color-accent-dark: #76369a;
  --flatify__color-accent-darker: #4a235a;
}
```

Read more on the [customization page](/docs/overview/customization).
