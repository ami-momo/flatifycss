## How they work

Each color in the [palette](/docs/overview/colors) gets four classes, `{name}` can be any palette color like `blue`, `danger` or `accent`:

| Class | Background | Text | Border |
| --- | --- | --- | --- |
| `.style-{name}` | primary shade | white (the darker shade for yellow and pink, normal text for light) | dark shade |
| `.style-{name}-light` | light shade | darker shade (white for dark, normal text for light) | primary shade |
| `.color-{name}` | | primary shade | |
| `.color-{name}-light` | | light shade | |

The `style-` classes also update the local CSS variables of a component, so a `.button.style-red` gets a red border too, not just a red background.
