The docs now live at [flatifycss.amimomo.me](https://flatifycss.amimomo.me), and the code at [ami-momo/flatifycss](https://github.com/ami-momo/flatifycss). I do not own the old flatifycss.com address anymore, so please update your bookmarks.

<!--truncate-->

While moving, I went through every page of the docs. A few examples had wrong class or variable names, some pages were missing, and there was not a single table. Now you can find tables for colors, CSS variables, helper classes and Sass settings, a page about [JavaScript](/docs/overview/javascript), and new pages for [range](/docs/forms/range), [textarea](/docs/forms/textarea), [float](/docs/helpers/float) and [text alignment](/docs/helpers/typography).

The next release is a small one:

- `$BACKDROP_OPACITY` finally does something.
- The old `flatify-rtl` files in `dist` were from version 1.5.3, now they are copies of the current files. Use `flatify.css` with `dir="rtl"` instead, they will go away in version 3.
- `main` in `package.json` points to a real file.

Nothing changes in your HTML. If something looks off, [open an issue](https://github.com/ami-momo/flatifycss/issues).
