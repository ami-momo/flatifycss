FlatifyCSS website is created with [Docusaurus](https://docusaurus.io/).
To contribute and improve the documentation please check the `/website/docs` directory.

```bash
bun install
bun start      # local dev server
bun run build  # static files in /build
```

It is deployed on Vercel at https://flatifycss.amimomo.me, with `website` as the root directory of the Vercel project.
